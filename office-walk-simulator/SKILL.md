# 办公室溜达神器

把用户想去的地方做成一段舒适、短促的第一人称“三步漫游”。交付 GIF，并在回复中用简短口令邀请用户在安全条件允许时跟走三步。

## 场景落地

- 保留用户指定的地点、季节、天气、时段和氛围；未指定时采用自然日光与写实风格。
- 对经纬度先解析大致地貌和地点名称。无法核实时说明画面是“基于坐标周边特征的想象”，不要声称是现场实拍或精确街景。
- 画面必须是自然视线高度的第一人称前进视角，路径清晰、地平线稳定；不要出现完整人物、自拍视角、第三人称背影、文字、水印或品牌标识。
- 避免悬崖边缘、车流、湿滑路面和其他会诱导危险模仿的构图。用户指定危险地点时，改成安全观景路径。

## 生成流程

1. 将用户描述整理成图像提示词，生成一张横向第一人称基准图。建议 3:2 或 16:9，写实、自然光、中央路径有明确纵深，并在四周留出少量可裁切余量。
2. 检查视角、路径连续性和安全性。只有在地点身份本身是关键且当前信息不可靠时，才查证坐标或地点；否则直接创作。
3. 用 `scripts/make_walk_gif.py` 将基准图变成三步循环 GIF。默认参数已经控制为轻微晃动，优先避免眩晕。
4. 预览 GIF：确认无黑边、无明显抽动、循环衔接自然，且主体未因裁切丢失。必要时降低 `--bob`、`--sway` 或提高 `--zoom`。
5. 交付 GIF；可同时给出基准图。说明场景是 AI 创作，若由坐标推断则说明其近似性质。

典型命令：

```bash
python3 scripts/make_walk_gif.py input.png output.gif
```

需要更舒缓时：

```bash
python3 scripts/make_walk_gif.py input.png output.gif --seconds 4.5 --bob 6 --sway 4
```

## 三步引导

交付时附上这一类短提示，不要把动作口令写进画面：

> 确认脚边没有障碍，扶稳桌沿；空间允许再起身。准备好后：左脚一步、右脚一步、再向前一步。若不方便站立，坐着交替抬脚也可以。

不要暗示运动、康复或治疗效果。用户提到眩晕、行动不便或空间狭窄时，默认改为坐姿交替抬脚。

## 输出要求

- GIF 为无限循环，默认约 43 帧、12 fps、3.6 秒、三次步伐起伏。
- 晃动幅度应让人感到在走路，但不能像手持相机剧烈抖动。
- 最终回复给出 GIF 和基准图的保存路径，并附上实际使用的图像提示词。
- 本技能的三张风格示意图位于 `assets/snow-mountain.png`、`assets/forest.png` 和 `assets/seaside.png`，只作为构图参考，不限制用户选择其他场景。
