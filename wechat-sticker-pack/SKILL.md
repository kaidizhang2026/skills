# 微信表情包制作技能

依据微信表情开放平台（sticker.weixin.qq.com）官方规范，制作一套可直接提审的微信表情包素材集。

## 适用场景

- 用户要求制作微信表情包、表情专辑（"帮我做一套表情包"、"做个微信表情包上架"）
- 用户已有素材图，需要裁切/缩放/压缩成符合微信规范的格式
- 校验已有表情包素材是否合规
- 将成套表情打包为规范的上传目录结构

## 核心规范速查（详细规范见 references/wechat-sticker-spec.md）

| 素材 | 数量 | 格式 | 尺寸 | 大小 | 关键约束 |
|---|---|---|---|---|---|
| 表情主图 | 16 或 24 张 | GIF | 240×240 | ≤500KB | 同套全动态或全静态；动态须永久循环；透明底；编号 01、02…… |
| 缩略图 | 与主图一一对应 | PNG | 120×120（专辑） | ≤200KB | 透明底；**无白色描边**；编号与主图一致 |
| 聊天页图标 | 1 张 | PNG | 50×50 | ≤100KB | 透明底、无白描边、无正方形边框 |
| 封面图 | 1 张 | PNG | 240×240 | ≤500KB | 透明底、无白描边、避免文字 |
| 详情页横幅 | 1 张 | PNG/JPEG | 750×400 | ≤500KB | 不透明底、避免白色背景、**禁止出现文字** |
| 赞赏引导图（可选） | 1 张 | PNG | 750×560 | — | 可含引导文字 |
| 赞赏致谢图（可选） | 1 张 | PNG | 750×750 | — | — |

审核红线：须原创或已授权；不得含二维码/外链/导流信息；付费与特效作品禁止任何推广元素（品牌、吉祥物、宣传语等）；文字无错别字；同一套表情须有充分差异。

## 工作流程

### 第 1 步：明确需求与创意策划

向用户确认或自行假设（并说明）以下要素：
1. **数量**：一套 16 张还是 24 张。
2. **动/静态**：动态（GIF）还是静态（PNG）。同一套必须统一。
3. **主题与角色**：原创角色或场景主题（如"打工人的日常"、"猫猫头"）。角色须有辨识度，风格统一。
4. **表情清单**：规划 16/24 个情绪与动作（如开心、流泪、点赞、晚安、委屈、摸鱼……），彼此差异要大。

若需要生成图像：用图像生成能力产出**高清原图（建议 1024×1024 以上、统一风格 prompt、同一角色）**，再进入第 2 步处理。生成 prompt 中应包含"透明背景"或纯色底以便抠图；表情中的文字要少、清晰、无错别字。

### 第 2 步：图片处理（规范适配）

使用 `scripts/process_stickers.py`（依赖 Pillow）处理素材：

```bash
# 从源图（任意尺寸）生成全套规范素材
python3 scripts/process_stickers.py --src <源图目录> --out <输出目录> \
  --mode album          # album=专辑(120缩略图) / single=单图(240缩略图)
  --format gif          # gif=动态 / png=静态主图
  --autocut white       # 可选：自动去除白色/纯色背景
```

脚本能力：
- 等比缩放并居中放置到目标画布，不拉伸变形（主图 240×240、缩略图 120×120、图标 50×50、封面 240×240、横幅 750×400）。
- 纯色底素材自动转透明底（`--autocut white` 去白底，或指定其他颜色）。
- 静态图统一输出 PNG 并压缩到大小限制内；GIF 超过 500KB 时自动降色板/减帧重压缩。
- 自动生成规范目录结构 `main/ thumbnail/ chat_icon/ cover/ banner/`。

横幅制作要点：背景必须不透明且避免白色系，可拼贴多个表情形象形成有故事性的画面，**画面中不要放任何文字**。

### 第 3 步：规范校验

打包提审前**必须**运行校验：

```bash
python3 scripts/validate_stickers.py <输出目录>
```

校验项：数量（16/24）、格式、像素尺寸、文件大小、编号命名与一一对应、GIF 循环属性（永久循环）、透明底（主图/缩略图/图标/封面）。校验全部通过才可进入第 4 步；未通过的按报错信息回到第 2 步修复。

### 第 4 步：交付与提审指引

1. 向用户展示输出目录中的关键素材（封面、横幅、部分主图），并给出完整输出目录路径。
2. 提供提审指引（附在回复或 README 中）：
   - 注册/登录 https://sticker.weixin.qq.com （需中国大陆身份）
   - 新建表情专辑 → 填写名称（≤8 个汉字）与介绍 → 按平台字段逐项上传：主图（每个表情填含义词，≤4 个汉字）→ 缩略图 → 聊天页图标 → 封面 → 横幅 →（可选）赞赏图
   - 提交后约 3–5 个工作日出审核结果；驳回后按驳回原因修改重新提交
   - 上架后可在专辑设置中开启"允许用户赞赏"

## 注意事项

- 生成图像时统一角色形象与画风：同一 prompt 骨架 + 固定角色描述，只替换情绪/动作部分。
- GIF 动画帧数建议 ≤30 帧，动作循环要流畅（首尾帧衔接）。
- 主图可加 2px 白色描边防锯齿；但缩略图、图标、封面**禁止**白描边。
- 表情之间差异要充分：仅换文字或局部细节的高度相似表情会被驳回。
- 不得包含二维码、联系方式、品牌 logo、真实名人肖像等侵权或导流元素。
- 用户素材为真人照片/明星形象时，提醒需获得授权。
