# 微信表情包制作规范（官方）

> 来源：微信表情开放平台（https://sticker.weixin.qq.com）《微信表情制作规范》《微信作品审核标准》。
> 上架审核依据本规范执行，任何一项不满足都可能导致驳回。最常见的驳回原因：尺寸错误、背景非透明、体积超标、命名不规范。

## 1. 投稿形式

- 支持静态表情、动态表情；单图表情或表情专辑。
- **表情专辑数量：16 张或 24 张一组**（部分静态专辑接受 8 张，稳妥起见按 16/24 制作）。
- **同一套表情要么全部动态，要么全部静态，不可混搭。**
- 同一套表情中各表情**风格须统一**，且**各表情图片之间应有足够的差异**（仅文字不同或整体高度相似会被驳回）。

## 2. 表情主图（聊天界面发送的图片）

| 项目 | 要求 |
|---|---|
| 数量 | 16 张或 24 张（专辑）；单图为 1 张 |
| 格式 | GIF（动态）/ GIF、PNG、JPEG（静态） |
| 尺寸 | 240 × 240 像素（正方形） |
| 大小 | 每张 ≤ 500 KB |
| 背景 | 透明背景（支持 Alpha 通道） |
| 循环 | 动态表情必须设置为**永久循环播放** |
| 帧数 | 建议 ≤ 30 帧，且 宽 × 高 × 帧数 ≤ 600 万像素（240×240 时约 104 帧为理论上限，但建议控制在 30 帧内） |
| 命名 | 必须按数字编号命名：`01`、`02`、`03`……（补零到两位） |

制作建议（官方未强制但影响观感）：
- 形象轮廓加 **2px 白色描边**，避免深色聊天背景下出现边缘锯齿（注意：主图可有白描边，缩略图/图标不可有）。
- 形象不能与画布边缘相切，四周留适当空隙。
- 配图文字要少而清晰，识别度高；文字尽量不超过画面 1/3。

## 3. 表情缩略图（聊天页与详情页展示的静态小图）

| 项目 | 要求 |
|---|---|
| 数量 | 与主图数量一致，**一一对应** |
| 格式 | PNG |
| 尺寸 | 表情专辑：120 × 120 像素；单图表情：240 × 240 像素 |
| 大小 | 每张 ≤ 200 KB |
| 内容 | 选取能表现主图的关键帧；如表情含文字，尽量选含文字的帧 |
| 禁止 | **不能有白色描边**；须为透明背景 |
| 命名 | 与对应主图编号一致：`01`、`02`、`03`…… |

## 4. 聊天页图标（下载后显示在聊天页表情列表）

| 项目 | 要求 |
|---|---|
| 数量 | 1 张 |
| 格式 | PNG |
| 尺寸 | 50 × 50 像素 |
| 大小 | ≤ 100 KB |
| 内容 | 选最具辨识度、清晰的图，画面简洁；建议仅含表情角色头部正面图像 |
| 禁止 | 无白色描边、避免锯齿、**透明背景**、避免白色背景、不要出现正方形边框/生硬直角边缘 |

## 5. 表情封面图（表情首页展示的代表图）

| 项目 | 要求 |
|---|---|
| 数量 | 1 张 |
| 格式 | PNG |
| 尺寸 | 240 × 240 像素 |
| 大小 | ≤ 500 KB |
| 内容 | 最具辨识度的形象，建议正面半身/全身像（不要只用头部）；画面简洁，避免装饰元素 |
| 禁止 | 无白色描边、**透明背景**、避免白色背景、无正方形边框；除纯文字类表情外**避免出现文字** |

## 6. 详情页横幅（进入详情页时展示）

| 项目 | 要求 |
|---|---|
| 数量 | 1 张 |
| 格式 | JPEG 或 PNG |
| 尺寸 | 宽 750 × 高 400 像素 |
| 大小 | ≤ 500 KB |
| 内容 | 与表情相关、画面丰富、有故事性；元素不得拉伸/压扁变形 |
| 禁止 | **避免出现任何文字信息**；**避免透明背景**；**避免白色或接近白色的背景**（色调要活泼明朗，与微信底色区分明显） |

## 7. 赞赏引导图 / 致谢图（可选，开通赞赏时需要）

| 项目 | 要求 |
|---|---|
| 赞赏引导图 | 750 × 560 像素，PNG，可加引导文字 |
| 赞赏致谢图 | 750 × 750 像素，PNG |
| 说明 | 不开通赞赏可省略；开通赞赏还需符合平台的赞赏开通条件 |

## 8. 命名与排序规范

- 主图与缩略图必须按 `01、02、03……` 数字编号命名，且**编号一一对应**。
- 详情页缩略图按序号**从左至右、从上至下**排列，请合理安排序号顺序。
- 推荐目录结构（便于按平台逐项上传）：

```
sticker-set-output/
├── main/          # 主图 01.gif ~ 24.gif（240×240, ≤500KB）
├── thumbnail/     # 缩略图 01.png ~ 24.png（120×120, ≤200KB）
├── chat_icon/     # 聊天页图标 icon.png（50×50, ≤100KB）
├── cover/         # 封面图 cover.png（240×240, ≤500KB）
├── banner/        # 详情页横幅 banner.png（750×400, ≤500KB）
└── reward/        # 可选：reward_guide.png(750×560) / reward_thanks.png(750×750)
```

## 9. 审核标准要点（《微信作品审核标准》）

1. **原创性**：作品必须原创或已获授权；素材与元素不得使用他人素材；涉及肖像权/版权需提供证明。
2. **内容合规**：不得包含违法违规、色情低俗、血腥暴力、侮辱诽谤等内容；不得含二维码、外链、联系方式等导流信息。
3. **禁止推广类**（付费表情/特效严格禁止；免费表情允许但不进商店推荐）：不得包含组织机构、商业产品、公共服务、旅游景点、事件活动相关信息（吉祥物、品牌、商品包装、宣传标语等）。
4. **文字**：文字清晰、无错别字；表情名称 ≤ 8 个汉字，含义词（表情含义）≤ 4 个汉字。
5. **差异化**：同一套表情须有充分差异；仅文字或局部细节不同的重复表情不能通过审核。
6. **使用场景**：适合聊天场景、生动有趣。
7. **审核周期**：通常 5 个工作日内反馈；待审核/被驳回/审核通过状态可直接修改，已上架表情每自然月限修改一次。

## 10. 提审流程速览

1. 注册微信表情开放平台（中国大陆身份个人/企业），完善艺术家资料。
2. 进入"表情专辑/单个表情" → 新建 → 填写名称（≤8 字）、介绍、表情含义词（每个 ≤4 字）。
3. 按目录逐项上传：主图 → 缩略图 → 聊天页图标 → 封面 → 横幅 →（可选）赞赏图。
4. 提交审核（约 3–5 个工作日）；通过后上架，可在表情商店搜索到。
5. 上架后可开启"允许用户赞赏"，收益直接进入绑定账户。
